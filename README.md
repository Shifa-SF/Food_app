💻 Installation & Setup

1. Clone the repository:
   
   git clone https://github.com/Shifa-SF/Food_app.git

2. Navigate to the project folder:
   
   cd Food_app

3. Install dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL shown in your terminal.
